# HarborShield 学习指南

这个项目的目标不是让你背代码，而是让你能够解释：问题是什么、模型为什么这样设计、结果意味着什么、模型有什么局限。

## 第一阶段：理解业务问题

先回答以下问题：

1. 为什么最便宜的航线不一定是最优航线？
2. 转运次数、航程、天气和拥堵为什么会影响货损概率？
3. 保险如何改变货主承担的损失，但为什么不会消除全部风险？
4. 成本、时间、风险和碳排放之间为什么存在冲突？

## 第二阶段：理解四个模型

### 1. 风险概率

项目使用 Logistic 函数把多个风险因素转换为 0—1 之间的概率。你需要理解各因素增加或减少风险的方向，不需要一开始手工推导所有公式。

### 2. 蒙特卡洛模拟

程序重复模拟数千次运输过程。每次都可能发生或不发生货损，也会产生不同的延误天数。最后用所有模拟结果的平均值和第90百分位数描述风险。

### 3. 保险模型

发生货损时，先扣除免赔额，再按保险覆盖比例计算赔付。货主承担未获赔付的剩余损失，同时支付保费。

### 4. 多目标决策

不同指标单位不同，因此先把它们标准化，再按照成本、风险、时间和碳排放的权重计算决策分数。分数越低，方案越符合当前偏好。

### 5. CVaR95 尾部风险

CVaR95 是最坏 5% 模拟结果的平均成本。货损属于低概率、高损失事件，P90 可能仍然落在“没有货损”的样本中，因此增强版使用 CVaR95 衡量尾部风险。

### 6. 整数优化

集装箱必须以整数分配到不同路线。OR-Tools 优化器在总箱量、单一路线最高占比和平均运输时间约束下，寻找风险调整成本最低的分配方案。

### 7. 官方公开数据

项目接入了新加坡海事及港务管理局的月度船舶到港数据。注意：船舶数量只能作为港口活动强度的背景信息，不能直接等同于拥堵或等待时间。

## 第三阶段：建议的每日学习顺序

- 第1天：运行项目，改变货值、货物类型和情景，记录结果变化。
- 第2天：阅读 `data/sample_routes.csv`，理解每一列。
- 第3天：阅读 `claim_probability`，只关注每个变量的影响方向。
- 第4天：阅读 `simulate_route`，理解一次模拟和多次模拟。
- 第5天：阅读 `rank_routes`，尝试改变权重。
- 第6天：修改一条路线数据，预测结果后再运行验证。
- 第7天：不用看文档，完成一次三分钟中文讲解。
- 第8天：用英文完成同样的讲解。
- 第9天：阅读 `docs/METHODOLOGY.md`，解释 CVaR95 和优化约束。
- 第10天：阅读 `docs/LITERATURE_AND_OPEN_SOURCE.md`，说明哪些内容来自论文、哪些是自主实现。

## 你必须能回答的面试问题

- 为什么选择这个问题？
- 为什么使用蒙特卡洛模拟，而不是只计算一个平均值？
- 模型中的概率是否是真实保险概率？
- 数据从哪里来，哪些是真实数据，哪些是模拟数据？
- 如何验证模型？
- 如果获得真实企业数据，你会如何改进？
- 为什么不使用深度学习？
- 项目与申请专业有什么关系？

最重要的正确回答之一是：当前模型用于展示透明的决策框架，系数尚未用真实理赔数据校准，因此不能作为真实保险定价工具。
