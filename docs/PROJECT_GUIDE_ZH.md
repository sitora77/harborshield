# HarborShield v0.2：你需要真正理解的项目

## 一句话

这是一个海运物流决策实验平台：比较直达、中转和海陆联运，在运费、货损、
保险、延误和碳排放之间做取舍；还可以把一批集装箱分配到不同路线，检验
“考虑风险”是否比“只考虑平均成本”更值得。

它不是保险报价器，也不是能给船舶导航的真实航路系统。

## 你的经历为什么适合这个问题

港口航道与近海工程让你理解港口和运输基础设施；货代实习中协助海运保险
操作的经历，给了你观察货物风险与运营取舍的入口。项目把这两个背景联系
起来，但不要把短期协助投保说成独立承保、定价或管理复杂供应链。

## 从输入到结果

1. 输入每个集装箱的货值、货种、包装、保险覆盖、免赔额与每天延误成本。
2. 选择正常、季风、港口拥堵或海峡中断的假设场景。
3. 模拟很多次“有没有货损、损失多少、延误多久”，得到成本分布。
4. 对单票货物，根据成本、风险、时间、碳排偏好排序。
5. 对整批货物，把箱子分配到三条服务路线，限制单一路线集中度与平均运输时间。
6. 用另一组随机样本比较四种方案，检查结果是否稳定、有无明确优势。

默认货值25万美元是**每箱**货值。20箱合计货值是500万美元。成本是美元，
碳排放是每箱假设的kg CO₂。地图上的连接线是示意，不是可航行路线。

## 本次修正了什么

- 原来三角分布的“最可能损失比例”被当作平均损失比例。现在保险费依据
  该分布的实际期望赔付计算，并计入免赔额。
- 原来批量分配把各路线风险相加。现在直接模拟整批成本，考虑共享延误和
  同时影响多票货物的冲击。
- CVaR的计算现在严格平均最坏5%的**样本质量**，正确处理并列与不足一个
  完整样本的边界权重。
- 箱子数量不能四舍五入绕过集中度限制。例如只有1箱、每路线最多70%，
  就没有合法方案，程序会告诉你不可行。

## 三个面试概念

**期望成本：**很多次可能结果的平均值。不是这次必然支付的金额。

**CVaR95：**最糟糕5%情况下的平均成本。它不是95%准确率，也不是最大损失。
一个方案平均较便宜，仍然可能在少数严重事件里代价很高。

**独立评估：**选择方案用一组模拟样本，检验方案用另一组。避免用同一份
样本“自己选、自己证明”。但两组都是同一假设模型生成，不等于用真实数据
验证了模型。

## 联合风险为什么重要

同一港口受到冲击时，多条运输路线可能一起延误。把20票货物分散到不同
路线，不一定能把风险完全分散掉。项目用一个“共享冲击强度”表示这种假设。
这个数字不是从真实历史数据估计出来的相关系数。

同一路线的箱子共享一次航行延误。共享强度为零，只代表不再有跨路线的
共同冲击，**不代表每一个箱子的成本都完全独立**。

## 当前实验到底说明什么

报告固定20箱、70%路线集中度、30天平均运输上限。每个场景用1,000个训练
情境选择方案，再用另外10,000个情境检验，并检查5个训练随机种子。
应用默认运输上限为22天，严重中断时可能无解，这和报告设置不同。

正常、季风、拥堵场景中，主训练种子下的联合风险和成本优先方案都是
直达6箱、釜山14箱。**这不能说成新方法降低了成本。**
海峡中断下，联合风险方案是直达10箱、釜山10箱；成本优先是6箱、14箱。
联合方案测试CVaR略低，但差值区间包含零，暂不能宣称统计上明确的改善。
完整数字以[自动生成报告](EXPERIMENT_REPORT.md)为准。

共同冲击增强时，平均成本变化不大，但尾部成本明显升高；不同训练随机
种子有时也改变推荐分配。这说明依赖结构和有限样本的不稳定性值得关注，
不是证明模型预测了现实。

## 哪些是真实数据

新加坡MPA的月度船舶到港数量是真实公开数据；路线费用、暴露指标、损失
概率系数、碳排放和共享冲击是假设数据。MPA到港数量单独展示，**没有拿它
训练货损或拥堵模型**。船多不必然意味着等待时间长。

## 如何展示

打开应用的“Joint-risk research lab”，点运行实验，展示四方案对比、
训练成本—尾部风险图、随机种子稳定性，最后下载结果。讲清楚问题、输入、
方法、结果和限制，比只展示漂亮图表更重要。

代码和资料可以公开在GitHub，主页用于引导别人阅读证据。GitHub Pages能
托管静态主页和报告，**不能运行Python/Streamlit后端**。没有部署Python
服务前，不要把静态报告链接叫作可操作的在线应用。

## 对不同申请方向的讲法

- MTM：海运数字化，连接港口工程、货代操作与决策支持。
- ISE：问题建模、概率、样本平均优化、约束和不确定性。
- SCM：供应链韧性、集中风险、货损和延误的总成本。
- 智慧交通：多式联运与中断响应；目前是服务路线分配，还不是AIS预测、
  真实路网寻路或微观交通仿真。

这些是项目的学科切入点，不是学校认可或录取保证。

## 你自己的学习任务

本项目有大量AI辅助代码和文档，不应声称全部独立手写。先做到：

1. 在电脑上跑起来，自己修改货值、保险覆盖和场景，解释变化。
2. 说明为什么三条路线的最优分配只能是整数，哪些条件会导致无解。
3. 解释CVaR、共同冲击、独立测试和“区间包含零”。
4. 自己设计并记录至少3个实验问题，不预设哪个方案赢。
5. 保存学习日志：你改了什么、为什么改、结果是什么、还不懂什么。

只有你实际完成且能讲清楚的部分，才能写成自己的能力。后续最重要的
提升是获得合法、可追溯的真实数据并校准，而不是堆更多复杂算法。
